# JavaScript Image Slider

A responsive and keyboard-accessible image slider built with vanilla JavaScript.

## Features

- Previous and next navigation
- Direct slide indicators
- Arrow, Home, and End keyboard controls
- Accessible current-slide state
- Responsive image presentation
- Reduced-motion support

## Built With

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- DOM events and component state
